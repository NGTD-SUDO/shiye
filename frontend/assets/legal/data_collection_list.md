# 拾页 个人信息收集清单

**版本号：v1.0**
**生效日期：2026年9月19日**

---

## 说明

根据《中华人民共和国个人信息保护法》及相关监管要求，本清单逐项列明本 App 收集的
全部个人信息，以及收集的目的、方式和范围。

**本 App 仅收集实现功能所必需的最少信息。**

---

## 一、收集清单一览表

| 序号 | 信息项 | 收集方式 | 收集目的 | 必要性 | 拒绝的后果 |
|---|---|---|---|---|---|
| 1 | **账号标识** | 设备本地自动生成 | 建立并识别账号 | **必要** | 无法使用本 App |
| 2 | **昵称** | 你主动填写 | App 内标识你的账号 | **必要** | 无法完成账号创建 |
| 3 | **笔记图片** | 你主动拍照/选择 | 文字识别、数字化存储 | **必要** | 无法使用识别功能 |
| 4 | **笔记识别文本** | 识别后自动生成 | 检索、校对、AI 分析 | **必要** | 无法使用检索功能 |
| 5 | **笔记标题** | 你主动填写（可选） | 组织笔记 | 非必要 | 仅影响笔记管理便利性 |
| 6 | **学科/章节名称** | 你主动创建 | 分类整理 | 非必要 | 仅影响分类便利性 |
| 7 | **AI 整理结果** | 你主动使用功能后生成 | 结构化笔记 | 非必要 | 无影响 |
| 8 | **学习统计数据** | 使用学情功能时计算 | 生成诊断报告 | 非必要 | 无法使用学情功能 |
| 9 | **答题作答内容** | 你主动填写 | 判分与诊断 | 非必要 | 无法使用测评功能 |

## 二、逐项详细说明

### 2.1 账号标识

| 项 | 内容 |
|---|---|
| **信息内容** | `dev_` 开头的 32 位随机十六进制字符串，例如 `dev_a3f8...` |
| **收集方式** | 由**你的设备在本地**使用安全随机数生成器生成 |
| **收集时机** | 首次登录时 |
| **存储位置** | 设备本地 + 服务器（作为账号唯一标识） |
| **收集目的** | 建立账号、关联你的笔记数据、实现数据隔离 |
| **必要性** | **必要**（没有它无法识别账号） |
| **是否属于敏感个人信息** | 否 |
| **特别说明** | **这不是手机硬件标识**（非 IMEI / Android ID / MAC 地址）。<br>**卸载本 App 后永久失效且不可恢复。** |

### 2.2 昵称

| 项 | 内容 |
|---|---|
| **信息内容** | 你填写的文本（最多 100 字符） |
| **收集方式** | 你在登录时或「我的 → 修改昵称」主动填写 |
| **收集目的** | 在 App 内标识你的账号 |
| **必要性** | 必要（账号创建所需） |
| **是否属于敏感个人信息** | 否 |
| **你的控制** | 可随时修改；可注销账号删除 |

### 2.3 笔记图片

| 项 | 内容 |
|---|---|
| **信息内容** | 你拍摄或选择的笔记照片 |
| **收集方式** | 你主动点击"拍照"或"从相册选择" |
| **收集时机** | **仅在你主动操作时**（不会后台自动获取） |
| **存储位置** | **你自行部署的服务器** |
| **收集目的** | ① 文字识别（OCR）② 供你随时查看原始笔记 |
| **必要性** | 必要（本 App 核心功能） |
| **是否属于敏感个人信息** | 可能涉及（取决于笔记内容） |
| **是否会外发** | **会** —— 使用识别功能时发送至百度智能云（见《第三方信息共享清单》） |
| **你的控制** | 可删除单篇笔记（图片文件一并物理删除） |

### 2.4 笔记识别文本（OCR 文本）

| 项 | 内容 |
|---|---|
| **信息内容** | 由图片识别出的文字内容 |
| **收集方式** | 识别完成后自动生成 |
| **收集目的** | ① 文字检索 ② 供你人工校对 ③ 作为 AI 分析的输入 |
| **必要性** | 必要 |
| **是否会外发** | **会** —— 使用 AI 功能时，其摘要部分发送至 DeepSeek |
| **你的控制** | 可在笔记详情页**直接编辑修正**；可删除笔记 |

### 2.5 笔记标题 / 学科名称 / 章节名称

| 项 | 内容 |
|---|---|
| **收集方式** | 你主动输入或修改 |
| **收集目的** | 笔记的组织与分类 |
| **必要性** | 非必要（不填不影响核心功能） |
| **是否外发** | 笔记标题会随 AI 分析发送至 DeepSeek；学科/章节名称不外发 |

### 2.6 AI 整理结果

| 项 | 内容 |
|---|---|
| **信息内容** | AI 生成的笔记结构化文本 |
| **收集方式** | 你主动点击"AI 整理"后生成 |
| **收集目的** | 供你查看与导出结构化的笔记内容 |
| **必要性** | 非必要 |
| **是否会外发** | **会** —— 使用 AI 整理时，**该页/该章的识别文本全文**会发送至 DeepSeek |
| **你的控制** | 可编辑；可删除笔记 |

### 2.7 学习统计数据

| 项 | 内容 |
|---|---|
| **信息内容** | 笔记页数、记录趋势等**由你的笔记自动计算**的统计值 |
| **收集方式** | 使用学情功能时在服务器端计算 |
| **收集目的** | 生成学习诊断报告 |
| **必要性** | 非必要 |
| **是否外发** | 会（作为 AI 分析的输入发送至 DeepSeek） |

### 2.8 答题作答内容

| 项 | 内容 |
|---|---|
| **信息内容** | 你在答题测评中填写的答案文本 |
| **收集方式** | 你主动填写并提交 |
| **收集目的** | 判分与生成针对性建议 |
| **必要性** | 非必要 |
| **是否外发** | 会（发送至 DeepSeek 判分） |
| **长度限制** | 每题最多 2000 字 |

## 三、本 App 不收集的信息

**本 App 明确不收集、不访问以下信息：**

| 信息类型 | 状态 |
|---|---|
| 地理位置 / GPS 定位 | ❌ 不收集 |
| 通讯录、通话记录、短信 | ❌ 不收集 |
| 剪贴板内容 | ❌ 不收集 |
| 相册全量内容 | ❌ 不访问（仅在你选择时访问你选中的图片） |
| 设备硬件标识（IMEI / Android ID / MAC） | ❌ 不收集 |
| 手机号码 | ❌ 不收集 |
| 身份证件信息 | ❌ 不收集 |
| 银行卡 / 支付信息 | ❌ 不收集 |
| 已安装应用列表 | ❌ 不收集 |
| 传感器数据 | ❌ 不收集 |
| 生物识别信息（指纹 / 人脸） | ❌ 不收集 |
| 用户行为轨迹 / 跨应用追踪 | ❌ 不进行 |

## 四、权限申请清单

| 权限名称 | 申请时机 | 用途 | 拒绝的后果 |
|---|---|---|---|
| **网络访问** | 应用启动（系统自动） | 与服务器通信 | 无法使用本 App |
| **相机** | 你点击"拍照"时 | 拍摄纸质笔记 | 仅无法拍照，可改用相册 |
| **相册/存储** | 你点击"从相册选择"时 | 选择笔记照片 | 仅无法从相册选图，可改用拍照 |

**本 App 不会在启动时预申请相机或相册权限。**

## 五、本地存储清单

以下信息保存在**你的设备本地**，不上传至服务器：

| 存储项 | 用途 | 卸载后 |
|---|---|---|
| 登录凭证（Token） | 保持登录状态 | 清除 |
| 账号标识 | 识别账号 | **永久失效** |
| 隐私政策同意状态 | 避免重复弹窗 | 清除 |
| 笔记整理结果缓存 | 减少重复请求 | 清除 |

## 六、你对个人信息的控制

| 权利 | 操作路径 |
|---|---|
| 查看 | App 内各页面直接查看 |
| 更正识别文本 | 笔记详情页 → 编辑 |
| 更正昵称 | 我的 → 修改昵称 |
| 删除单篇笔记 | 笔记详情页 → 删除 |
| 删除学科（含其下全部笔记） | 学科列表 → 长按 → 删除 |
| **注销账号（删除全部数据）** | 我的 → 账号 → 注销账号 |
| 撤回同意 | 我的 → 隐私政策 → 撤回同意 |
